# Telecom Fault Trend Analysis Dashboard

# 📌 Project Overview
This Power BI dashboard analyzes telecom network fault data and provides insights into fault occurrences, downtime, and OFC performance. The solution uses Power Query for data cleaning and DAX for business calculations.

🎯 Business Objective
The objective of this dashboard is to:

Monitor fault occurrences across OFC IDs
Identify the most problematic OFCs
Track fault trends by date
Analyze downtime and restoration performance
Provide interactive filtering for quick investigation
# 📊 Key KPIs
+ Total Faults
+ Unique OFCs Impacted
Total Downtime Hours
Average Fault Duration (Hours)
